# avito — измеренные ловушки

Каталог того, на чём код реально ломался. Читать при отладке или при добавлении
новой категории. Каждый пункт — замер, не предположение.

## Выдача

**1. `allItems` мешает два списка.** По Ульяновску `mainCount=16`, а записей 46:
16 с `analyticParams.place='serp-items'` (своя выдача) и 30 с `'extra-items'`
(добор из других городов). Без фильтра «нашёл 46 в Ульяновске» — вранье.

**2. `locationId` в query НЕ фильтрует гео.** С `locationId` Ульяновска пришли
Химки, Котельники, Уфа, Москва, Тверь. Город задаётся ПУТЁМ (`/omsk/...`).

**3. Дата публикации — в `freeForm` по id узла** `sortTimeGrid`. Регуляркой по
JSON ловилось «1 дня» из «Доставка от 1 дня». Часто пустая (Саратов: 20 из 22) —
тогда время в `posted_ts` (unix), `report.py` печатает его как дату.

**4. Фильтры состояния и рейтинга в URL не работают.** `params[110396]` (Б/у),
`params[196498]` (рейтинг 4,7+) — в `searchParams` ответа не попадают, выдача не
меняется. Фильтровать по полю `props` после сбора.

## Карточка

**5. Автомобили рисуются на клиенте.** В HTML и `__initialData__` полей карточки
нет — только `item.itemCardView` с аналитикой. Решение: `L.hydrate()` с
ожиданием `item-card-parameters-name` (~4.5 с). Ответ помечен `src:'hydrate'`.

**6. Описание в DOM обрезано.** У авто в разметке 79 символов и «...Читать
полностью»; после клика — 1596. Кнопка без `data-marker`, ищется по тексту.
`wdlib.hydrate` жмёт её сам (`expand:false` отключает).

**7. Характеристики: только листовые узлы.** `[data-marker^="item-properties-item("]`
ловит и родителя, который отдаёт склеенный текст → тройные дубли
(«Состояние: Б/у», «Состояние:», «Б/у»). Фильтр `/\)$/` обязателен.

**8. Мёртвая ссылка отвечает 200.** `item.item = {redirect:{...}}` без `title`,
уводит в категорию. Проверять `x.redirect && !x.title`.

**9. Поле `contacts` непостоянно.** На одной и той же карточке то есть
(`contacts.list` с `type: phone|messenger`), то отсутствует. Поэтому
`can_call`/`can_message` = `null`, когда поля нет: `false` означало бы
«связаться нельзя», а это неизвестно.

## Продавец

**10. Рейтинг нельзя считать по звёздам.** `rating-stars/star-N` — иконки,
блоков два по пять → выходило «10». Правда: `[itemprop="ratingValue"]` и текст
«N отзыва». Наивная склейка «5,0\n233» давала `0233`.

**11. «19 отзывов» ≠ 19 продаж.** В профиле Романа (omsk, 8415191510) 10 отзывов
как продавцу и 9 как покупателю. Роль — в `titleCaption` записи.

**12. Список отзывов режется на 25.** У магазина с 233 отзывами больше не
отдаётся. API пагинации не найден: `/web/1/user/<hash>/ratings`,
`/api/1/user/<hash>/ratings` и родня → 404. Работающий роут только один:
`/api/1/user/profile/items?sellerId=<hash>` (объявления продавца).

## Цена

**13. Цена вакансий — диапазон.** «1 500 — 3 290 ₽ за смену» при удалении
нецифр превращалась в `15003290`. `L.num()` берёт число до тире, полная строка —
в `price_text`.

## Каналы

**14. Фото качаются из шелла свободно.** `img.avito.st` антибот не режет: curl
отдаёт 200 и JPEG 720×960. Ограничение только на выдачу и карточки.

**15. Внутренний `/web/1/main/items` не годится.** Отвечает 200, но
`priceDetailed.value = 0`, `priceMax` игнорируется, дубли между страницами
(43 уникальных из 90). `/api/9/items` → «обновите приложение».

**16. Канал нестабилен.** Карточка через curl: `curl 1/3`, `none 1/3`, остальные
UA 0/3. Выдача в один час проходила 10 раз подряд, через полчаса — 429 десять
раз подряд тем же UA. Мерить долей успеха (`probe --tries 3`), не одной пробой.

**17. Браузерный UA хуже тупого.** Авито пускает `curl/8.14.1` и Googlebot,
режет `Chrome/120`. WAF ловит расхождение UA и TLS-отпечатка, а не сам curl.

**18. `browser_use` — основной безопасный канал.** Встроенный браузер Minis
несёт `navigator.webdriver=false`, отдаёт реальные `languages`, имеет
полную историю cookies. На замере 2026-09-07: 10 fetch подряд за 16 сек,
все 200 OK с `server: QRATOR`. Капчу не показало. Прямой curl с того же
IP параллельно давал `429`. Вывод: для анонимного чтения Авито
использовать `browser_use`, не `web-deep/channel.py`.

**19. Капчу Авито решать автоматически НЕ пытаемся.** Это против правил
площадки и условий использования. Если `browser_use` упёрся в капчу —
остановиться, показать пользователю, не обходить. Ручной ввод пользователя
легитимен, автомат — нет.

**20. Тайминги для безопасной работы через `browser_use`.** По замеру:
3 запроса подряд (≈1.3 с каждый) = 200. 10 запросов за 16 сек = 200.
Свыше 1 запроса в секунду на сессию рискованно. Безопасный ритм:
2-3 секунды между запросами, не больше 30 запросов за сессию без
перерыва 2-3 минуты. После паузы QRATOR сбрасывает счётчик.

**21. URL-параметры для фильтров Авито.** Работают: `q=`, `pmin=`, `pmax=`,
`p=N` (пагинация), `s=N` (сортировка), `params[196498]=4.7` (рейтинг).
НЕ работают: `params[110396]` (Б/у — игнорируется), фильтр по гео через
query (`locationId`) — задаётся ПУТЁМ (`/omsk/...`). См. п.2.
