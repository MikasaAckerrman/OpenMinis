# avito/config — конфиги для сканера

YAML-конфиги описывают, ЧТО искать и КАК отфильтровывать. Один mission-файл —
одна задача («найти RTX 3070 в Ульяновске до 25к»). Словари переиспользуются
между mission'ами.

## Что лежит

```
config/
  dictionaries/
    nvidia-gpu.yaml     # синонимы NVIDIA: rtx/трикс/ар-ти-икс/GeForce
    amd-gpu.yaml        # синонимы AMD: radeon/rx/амд
    models.yaml         # серии и модели по поколениям (3060/3070/4060/5070…)
  missions/
    rtx3070-ulyanovsk.yaml   # пример готовой задачи
  filters/
    desktop-only.yaml   # исключения: ti/m/laptop/ноутбук
    in-this-region.yaml # правило гео для региона
```

## Соглашения

- mission: одна задача, конкретный фильтр, конкретный регион
- dictionary: переиспользуемый список синонимов и моделей
- filter template: переиспользуемый набор правил отсечения

Когда категория меняется (процы, память, телефоны) — добавляются новые словари
и mission-файлы. Логика сканера не меняется.
